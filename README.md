# simple-native

[![Build](https://img.shields.io/github/actions/workflow/status/SageMik/sqlite3_simple/simple.yml?branch=simple-native&style=for-the-badge&logo=github)](https://github.com/SageMik/sqlite3_simple/actions)

该分支编译和维护用于主分支 Dart/Flutter 项目的 [@wangfenjin/simple](https://github.com/wangfenjin/simple) 原生库，通过
Github Actions 进行持续集成（CI），详见 [`.github/workflows/simple.yml`](.github/workflows/simple.yml) 。

可前往 [Release](https://github.com/SageMik/sqlite3_simple/releases) 查看 `simple-native vX.Y.Z` 编译产物，通过
`libsimple.zip` 一键获取所有平台编译产物，通过 `libsimple.dart.zip` 获取专用于主分支的原生库。

> [!TIP]
>
> 1. 自 `Nv2.0.0` 开始，本库所用拼音文件替换为 [`zdic.txt`](zdic.txt) ，以解决原拼音文件存在大量不常用读音的问题（例如输入q，会匹配到
     `示(U+793A, qí)`、`客(U+5BA2, qià)` 等），因此与上游存在差异。
> 2. 主分支自 `v3.0.0` 起引入 [Dart Hooks](https://dart.dev/tools/hooks) 管理原生库，不再逐平台引入依赖。但部分原生库本就从平台依赖中诞生（如
     Android 平台，原生库是从 [`simple-native-android`](https://central.sonatype.com/artifact/io.github.sagemik/simple-native-android) 的 `aar` 包中解压出来的），因此仍会保持维护。
